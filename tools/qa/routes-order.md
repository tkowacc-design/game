# 4カットの発注（試作） 画面ルート一覧（テスト用）

対象は `anime-order.html`。制作デスクの机の上で、4カットのコンテから原画を発注し、戻った原画を確かめて仕上げへ渡す試作。机で考えている間は時間が進まず、時計が進むのは「佐伯に手配を頼む」（月12:30）と「この順番で送る」（火13:00）のときだけ。大きな修正のあとは、この一覧のすべてを実際に操作して確かめる。画面や操作を足したら、この一覧にも足す。

画面は3列：左に一覧 → まん中に机（作業台） → 右に詳細（いちばん下に「〇〇にできること」）。1240px以下は「一覧と机」と「詳細」の2列、860px以下は1列（机 → 一覧 → 詳細の順。まず佐伯のひとことと作業台が見える）。

確かめること（どのルートでも共通）
- ページエラー・コンソールエラーが出ない
- 画面の文字に `undefined` `NaN` `[object Object]` が出ない
- 横スクロールが出ない（1440 / 1024 / 768 / 390 / 320 px）
- 選んだものが黄色の枠で示され、右（860px以下では下）に詳細が出る。もう一度押すと選択が外れ、「この場面でやること」に戻る
- 詳細のいちばん下に「〇〇にできること」があり、押せない操作は理由が赤字で書いてある
- 選んだものを置ける場所は黄色くなり、その場所に「ここに置く」系のボタン（「選んだ資料を出す」「このカットを頼む」「この袋に入れる」「ここに並べる」「この束へ」など）が出る
- マウスでは、一覧や机のものを置き場所へドラッグしても同じことができる（置ける場所の上でだけ枠が濃くなる）
- スマホ幅（390px）でボタン・チップのタップ領域が44px以上
- 上の帯の段取り（1〜6）は、いまの段取りが黄色。行けない段取りは押せない

テストでの状態の作り方：ページは `pagehide` で保存するので、`localStorage` を書いてから再読み込みすると上書きされる。`context.addInitScript` で、ページのスクリプトより先に `localStorage.setItem("animep.order", …)` を入れる。状態はページ内の `Engine`（`Engine.newGame()` など）で作れる。

## 1. はじめる
- [ ] 初めて開く → 「4カットの発注（試作）」の説明 → 「はじめる」で「1 コンテ」
- [ ] 上の帯：段取り1〜6・時計「月 10:00 12:30に佐伯が出る」・遊び方・最初から
- [ ] 「遊び方」→ 閉じる／Esc
- [ ] 「最初から」→ やり直す／やめる／Esc

## 2. コンテ（1）
- [ ] 机にコンテ4カット（C1〜C4。絵・カット番号・秒数・内容。C3は★手元、C4は★芝居）と、場面「第1話 Bパート「雨の部室」 11月・放課後」
- [ ] 左の資料棚（人物4・小物4・背景4・参考2）。資料を押すと右に絵とメモ。ミオ（冬服）とギター（アコースティック）には「見る資料」のリンクがあり、押すとその資料に切り替わる
- [ ] 「今回の資料に出す」→ 「今回の資料」に並び、棚に「出した」。もう一度押すと「棚に戻す」
- [ ] 資料を「今回の資料」へドラッグ／今回の資料から棚へドラッグで戻す
- [ ] コンテのカットを押すと右に大きなコンテ（できることはない）
- [ ] 佐伯のひとことが、出した枚数で変わる
- [ ] 「次へ：原画マンを探す」

## 3. 原画マン（2）
- [ ] 机：カット4枚（頼んだ人／未定）、原画マン4人（作例の絵・得意・苦手・速さ・場所）、空き予定の表（緑＝空き、赤い点線＝火曜12:00）
- [ ] カットを選ぶ → 右に「森さんに頼む」など4人ぶん。押すと頼む。もう一人に頼み直すと移る。「頼むのをやめる」
- [ ] 原画マンを選ぶ → 右に「C1を頼む」など4カットぶん
- [ ] 一人に3カット目を頼もうとすると押せない（「〇〇さんはもう2カット持っている」）
- [ ] カットを原画マンの枠へドラッグ／「頼むのをやめるときは、ここへ」へドラッグ
- [ ] 森さんに2カット頼む → 枠に「空き（月 13:00〜16:00 だけ…）に収まらない」、佐伯が「空いてる時間に収まりません！」
- [ ] 「戻る：コンテ」「次へ：発注する」

## 4. 発注（3）
- [ ] 机：頼んだ人ごとの袋（コンテのチップ・資料のチップ・×で出す）、佐伯の回る順番（↑↓）、見込みの表（青い線＝袋が届く、濃い色＝描いている、赤い点線＝回収）
- [ ] 左の「今回の資料」を選ぶ → 右に「〇〇さんの袋に入れる（C1）」。入れると「〇〇さんの袋から出す」に変わる
- [ ] 資料を袋へドラッグ
- [ ] 今回の資料にない資料は袋に入れられない（棚に戻すと袋からも出る）
- [ ] 同じものの違う版（ユイ冬服と夏服など）を同じ袋に入れる → 袋に赤字「同じものが2種類入っている…」、見込みが1時間ずつ遅れる
- [ ] 回る順番：宮下さんや作画部屋の人を森さんより先にすると、森さんが「空きのうちに描き終わらない」になり、「佐伯に手配を頼む」が押せない（理由が出る）。森さんを先にすると描き終わる
- [ ] 頼む人が決まっていないカットがあると「佐伯に手配を頼む」が押せない
- [ ] 「佐伯に手配を頼む（月12:30出発）」→ 「昨日からの記録」（佐伯が袋を届ける・迷った電話・描き終える・回収）→「原画を確かめる」で「4 照合」。時計は「火 13:00」
- [ ] 手配したあとは段取り1〜3に戻れない

## 5. 照合（4）
- [ ] 左：戻った原画（まだ／作監へ／仕上げへ）、コンテ、袋の記録（何を入れたか・届いた時刻・描き終えた時刻）、資料棚（たたまれている。開くと資料が並び、再描画しても開いたまま）
- [ ] 原画を選ぶ → 右に絵・タイムシート（C4は原画4枚・溜めあり、または2枚・溜めなし）・原画マンのひとこと。できること：コンテと並べる／見比べ台の1〜3に並べる／作監に確認する束へ／仕上げへ渡す束へ
- [ ] 「コンテと並べる」→ 見比べ台の1にコンテ、2に原画
- [ ] 見比べ台：コンテ・原画・資料・袋の記録を並べられる。「外す」「入れ替える」。ドラッグでも並べられる
- [ ] 袋に入れなかった資料の分だけ、原画がコンテと違う（例：ユイ冬服なし→白い半袖、カポタストなし→カポがない、部室（夕方・雨）なし→窓に太陽、ドア側なし→ドアが右、マフラーなし、Gコードなし→指の形が違う）。紺のブレザーは線画では斜線
- [ ] 早瀬さんの原画は、袋に入れても小物（カポ・マフラー）がない。小林さんの手のカットは指が崩れる。★手元を森さん以外、★芝居を宮下さん以外に頼むと崩れる・硬い
- [ ] 作監に確認する束：確認メモ（服・小物・楽器・背景・手・芝居）を押して切り替えられる。仕上げの束に移すとメモは消える。「戻す」で未分類へ
- [ ] まだ分けていない原画があると「次へ：渡す順番を決める」が押せない（理由が出る）
- [ ] 「昨日からの記録を見る」→ 記録 → 閉じる／Esc

## 6. 渡す（5）
- [ ] 作監と仕上げの両方に原画があるとき：「仕上げの束を先に届ける」「作監の直しを待って、まとめて届ける」を切り替えられる。片方だけのときは説明の文だけ
- [ ] 見込みの表：大島さん（カットごとの時間）、佐伯（ミナトへ届く時刻）、ミナト（塗る時間。斜線は夜の休み。間に合わないカットは赤で「線のまま」）
- [ ] 確認メモを増やす・減らすと、大島さんの見込みが変わる
- [ ] 「まとめて届ける」と、作監に1カットでも回していれば最後のカットが「線のまま」になる（仕様）
- [ ] 左の「大島さん（作監）」「ミナト（仕上げ）」を押すと右に条件
- [ ] 「戻る：照合」で戻って分け直せる
- [ ] 「この順番で送る」→「6 映像」。時計は「水 10:00」

## 7. 映像（6）
- [ ] 映像が C1→C2→C3→C4 の順に秒数どおり流れる（雨が降る、カポをつける、弦が震える、ドアが開いてミオが現れる、ユイが振り向く。★芝居が硬いと溜めなしで振り向く）。C4で「ミオ「……まだいたの？」」。最後に「おわり」と「もう一度見る」
- [ ] 塗りが間に合わなかったカットは線画のまま流れ、「線のまま（塗りが間に合わなかった）」と出る
- [ ] あなたの見立て（「4カット、ちゃんとつながった。」／「つながったけど、〇〇……」／「C4が線のまま撮影に入った……」）と、数（作監で直した・見逃した・作監に回したが直しなし・線のまま）
- [ ] カットごとの結果：作監が直したもの（「発注で防げた：」の理由つき）、残ったところ（理由つき）、仕上げに届いた時刻と塗り上がり
- [ ] 誰がどう動いたか（月12:30からの記録に、大島さん・佐伯・ミナトの動きが続く）
- [ ] 左のカットを押す → 右に結果と「このカットから映像を見る」
- [ ] 「最初からもう一度」→ やり直す

## 8. 保存と再開
- [ ] 1〜3の途中で再読み込み → 同じ段取り・同じ選択・今回の資料・頼んだ人・袋・順番のまま
- [ ] 「昨日からの記録」が出ている状態で再読み込み → 記録が出たまま
- [ ] 4の途中（見比べ台・束・メモ）で再読み込み → そのまま

## 9. 狭い画面
- [ ] 1024px：右に詳細、左に一覧と机。一覧は数列に並ぶ。詳細が長いときは詳細の中だけスクロールする
- [ ] 390px：1列。上の帯は画面に貼りつかない。一覧を押すと詳細までスクロールする（1秒ほど待ってから測る）
- [ ] 320px：横スクロールなし。コンテは1列
