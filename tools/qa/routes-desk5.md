# デスクの5日間（試作） 画面ルート一覧（テスト用）

対象は `anime-desk5.html`。PCゲーム（スマホ向けには作らない）。制作デスクとして、進行3人（川口・真壁・佐伯）に3話（ep1〜ep3）を5日間（1日3ブロック、計15ブロック）で仕上げさせるテキスト中心の試作。時間は「進める」を押したときだけ進む。大きな修正のあとは、この一覧のすべてを実際に操作して確かめる。画面や操作を足したら、この一覧にも足す。

確かめること（どのルートでも共通）
- ページエラー・コンソールエラーが出ない
- 画面の文字に `undefined` `NaN` `[object Object]` が出ない
- 横スクロールが出ない（1920×1080 / 1440×900 / 1280×720 / 1024×768）
- 工程表の数字に「確・報・推」の区別が付いている。隠れた原因（データ不備・原画マンが止まっている・他社へ移る・メンテ）は、報告・電話・結果でしか表に出ない
- 押せない電話は、ボタンの文字が理由になる（「作業できる仕上げ待ちが3袋未満」「もう頼んだ」「メンテ中で動かせない」「終わっている」）。その日の電話を使ったあとは全部押せない

## 1. はじめる
- [ ] 初めて開く → はじめに（遊び方の要点）→「はじめる」で 1日目 午前
- [ ] 上の帯：日付と時間帯・電話 残り1回・詳細・遊び方・最初から
- [ ] 1日目午前の報告：仕上げ会社「ep1の仕上げ待ち2袋、データに不備があるかもしれません…」、川口・真壁・佐伯の上がり報告
- [ ] 工程表：ep1の仕上げ待ちは「2袋（うち2袋は作業できるか未確認）」、手元の余裕は「最大1ブロック（推）／不備があれば0」

## 2. 3人の配置と進める
- [ ] 3人それぞれに選択欄（回収：ep1〜ep3、対応：各話数の原画マン／仕上げ会社、待機）。指示しなければ担当の回収
- [ ] 「進める」→ ブロックの結果（何が起きたか・人物のひとこと・各話数の仕上げ数）と、次のブロックの報告
- [ ] 問題のない所へ対応に出すと「空振り」と出る
- [ ] 締切の過ぎた話数は回収を選べない（「締切が過ぎている」）

## 3. 電話
- [ ] 確認（原画／仕上げ）→ 答えが「届いた報告」に「電話」として出る。答えを見たあとで指示を変えられる
- [ ] 原画を確認すると、上がり待ちが「確（電話で確認）」になる
- [ ] 頼み込み → そのブロックの仕上げが3袋（結果に +3）
- [ ] 1日1回。使ったら全部押せない。翌日の午前に戻る

## 4. 報告と出来事（状態から決まる）
- [ ] 1日目に欠けを直さないと、次のブロックで仕上げ会社から「止まっています」
- [ ] 2日目朝：川口の噂（千早さんをよその現場で見かけた）、佐伯「みんな順調です！」、仕上げ会社のメンテ・データ形式の話
- [ ] 2日目中に千早さん（ep3の原画マン）へ対応しないと、3日目朝に降板の連絡。引き継ぎは2回回る（土屋さんが引き受ける）
- [ ] 3日目朝：真壁「坂巻さんが少し遅れ気味で……様子見です」。午前に対応しないと、4日目朝「連絡がつきません」。呼び戻すと翌朝から戻る
- [ ] 前日の袋を残すと、翌朝その原画マンが描かない（担当の報告に出る）
- [ ] 5日目朝：ep3のラインは午前メンテ（結果に「メンテナンスで止まっていた」）

## 5. 詳細
- [ ] 「詳細」で予定表（1〜5日目、今日に色）と締切の見込み（把握している情報だけ）。もう一度押すと閉じる

## 6. 終わり
- [ ] ep1は4日目夕方、ep2・ep3は5日目夕方で締切。完成なら担当のひとこと、不足なら「止め絵でつなぐ」
- [ ] 5日間のあと：結果の表・最後のブロックの結果・指示の記録・ふりかえり（3つの質問の欄。書いた内容は残る）・最初からもう一度

## 7. 保存と再開
- [ ] 途中で再読み込み → 同じブロック・同じ報告・選んでいた指示と使った電話もそのまま
- [ ] 電話の答えを見たあとで再読み込み → 答えも電話の残りもそのまま
- [ ] 終わりの画面で再読み込み → 終わりの画面のまま（ふりかえりの記入も残る）
