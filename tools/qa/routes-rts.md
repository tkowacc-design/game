# 進行RTS（試作） 画面ルート一覧（テスト用）

対象は `anime-rts.html`（絵は `assets/rts/`）。PCゲーム（スマホ向けには作らない）。制作デスクの席から見たドット絵の一人称画面で、1週＝120秒。常設のパネルはない。大きな修正のあとは、この一覧のすべてを実際に操作して確かめる。画面や操作を足したら、この一覧にも足す。

確かめること（どのルートでも共通）
- ページエラー・コンソールエラー・画像の読み込みエラーが出ない
- 画面の文字に `undefined` `NaN` `[object Object]` が出ない
- 画面の下・右に常設のパネルがない。指示は押した進行のそばに出る
- 押せない指示は、ボタンの文字が理由になる（「車を使用中（◯◯）」「空きカットなし」「担当の話数ではない」「帰宅している」「今週はもう徹夜させた」など）
- 見込みは「あなたの見立て」のひとことで出る（カット数など確定した数は数字でよい）
- 横スクロール・縦スクロールが出ない（1920×1080 / 1440×900 / 1280×720 / 1024×768）
- 時間は requestAnimationFrame で進む（等速で1週＝120秒）。結果は1秒ほど待ってから測る

## 1. はじめる
- [ ] 初めて開く → 遊び方 →「はじめる」で第1週 月曜 10:00 から動く（原画マンは最初から8割埋まっている）
- [ ] 左上：第1週・曜日と時刻・残り◯秒・「第1話 放送まで あと4週」・曜日のゲージ

## 2. 右上の操作
- [ ] 停止／再開、スペースキーでも ／ ×1・×2
- [ ] ？ → 遊び方 → 閉じる／Esc ／ 最初からやり直す → やり直す／やめる

## 3. 席と時間
- [ ] 進行3人（佐伯＝左手前、川口＝右奥、真壁＝右手前）を押す → そばに指示。もう一度押す／部屋の何もないところ／Esc で消える。1〜3キーでも選べる
- [ ] 川口と真壁の重なりは、手前に描かれている方が選ばれる
- [ ] ポーズ：指示待ち＝待機、作業＝作業（原画営業は電話）、報告＝報告、休憩・疲れ＝疲労、寝る＝睡眠（zZZ）、外回り中・帰宅中＝いない（椅子だけ）
- [ ] 24時になると、徹夜でない進行は帰宅する（作業は途中で止まり、翌日続きをやる）。10時に出社する
- [ ] 徹夜を指示した進行は夜も残る。仕事がなければ机で寝る
- [ ] 仕事が終わると報告の吹き出し。押すまで消えない。押すと消えて、指示の下の欄に「さっきの報告」。帰宅中・外回り中でも、空いた椅子の上に出たまま
- [ ] 時間帯で部屋が昼・夕・夜に変わる
- [ ] ホワイトボード：12話（担当の頭文字）・いま止まっているもの・状況（進行中／遅れ気味／要確認／完了、放送済みは完成・止め絵・落とした）
- [ ] 撮入れ準備をすると、ホワイトボードの下の棚にカット袋がたまる（「撮入れ棚 ◯袋」）。外回りに出ると車に積まれて棚からなくなる（撮影には途中で届く）

## 4. 指示（進行のそば）
- [ ] 原画営業・作打ち・動仕撒き・撮入れ準備：自分の担当の話数だけ。担当の話数が2つあれば「どの話数？」
- [ ] 外回り：1人が行けば全員の話数の原画を回収し、出るときに棚の袋を積んで撮影に届ける（報告に回収数と届けた袋の数）
- [ ] 休憩（体力が十分なら押せない）／寝る（眠くなければ押せない）／帰宅（翌日10時に来る）
- [ ] 今夜は徹夜（1人週1回。2回目は「今週はもう徹夜させた」）
- [ ] 作業中なら「やめさせる」
- [ ] 指示の下の欄：名前・状態・体力・担当の話数・いまやっていること・さっきの報告・あなたの見立て

## 5. 車の鍵・スマホ・パソコン
- [ ] 車の鍵を進行までドラッグ → 外回りへ（鍵が机から消える）。出せない相手は理由が出る。押すだけだと案内
- [ ] 机のスマホを押す → 手前にスマホ。メールに「受け入れる」「キレて出させる」で返事。同じ相手には二度とキレられない（「もうキレた相手」）。返事をしないと1日で「受け入れた扱い」
- [ ] 受け入れた結果：カットを返される→空きが増える、遅れる→その人が遅くなる、グロスの遅れ→上がりが延びる、動仕の遅れ→上がりが1日延びる
- [ ] 右手前のパソコンを押す（1024×768 でも文字が小さくなりすぎず、表は窓の中で横に送れる）→ 進行表（話数ごとに担当・放送まで・原画マンの人数と埋まり・あと何人足りない・作打ち・原画中・回収待ち・撒き待ち・動仕中・撮入れ待ち・棚・撮影済み・止まっているもの。止まっているマスは黄色）
- [ ] パソコンの原画マン：名前・抱えているカット（話数ごと）・状態・キレた相手
- [ ] パソコンのグロス：会社ごとに空き／担当中。空いている会社に「第◯話を出す（あと◯日で上がる・間に合わない）」→ 出すとその話数はグロス（担当の手が空く）
- [ ] スマホ・パソコンは「机に戻す」「閉じる」／外を押す／Esc でしまう

## 6. 週の終わりと放送
- [ ] 週の終わり・放送終了の画面が出ているあいだは、1〜3キーを押しても指示は出ない
- [ ] 1週たつと「第N週 おわり」→「第1話 放送まで あと◯週」→「第N+1週へ」で次の週（新しい話数のコンテが上がる。担当は順番）
- [ ] 第4週の終わりに第1話が放送 → 結果と「放送中 残り11話」
- [ ] 第15週の終わりに第12話が放送 → 全12話 放送終了（評価・各話の結果・キレた回数・徹夜の回数）→ もう一度

## 7. 保存と再開
- [ ] 途中で再読み込み → 同じ時刻・同じ状態で、止まった状態から再開
- [ ] 週の終わりの画面で再読み込み → その画面のまま
- [ ] 放送終了の画面で再読み込み → その画面のまま
