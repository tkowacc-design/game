# 進行RTS（試作） 画面ルート一覧（テスト用）

対象は `anime-rts.html`（絵は `assets/rts/`）。制作デスクの席から見たドット絵の一人称画面で、1週＝120秒。常設のパネルはない。大きな修正のあとは、この一覧のすべてを実際に操作して確かめる。画面や操作を足したら、この一覧にも足す。

確かめること（どのルートでも共通）
- ページエラー・コンソールエラーが出ない（画像の読み込みエラーも）
- 画面の文字に `undefined` `NaN` `[object Object]` が出ない
- 画面の下・右に常設のパネルがない。指示は押した進行のそばに出る
- 押せない指示は、ボタンの文字が理由になる（「車を使用中」「空きカットなし」「体力は十分」など）
- 見込みは「あなたの見立て」のひとことで出る（撮影済みのカット数など確定した数は数字でよい）
- 横スクロール・縦スクロールが出ない（1920×1080 / 1440×900 / 1024×768 / 390×844 / 320×568）
- 時間は requestAnimationFrame で進む（等速で1週＝120秒）。結果は1秒ほど待ってから測る

## 1. はじめる
- [ ] 初めて開く → 遊び方（止まっている）→「はじめる」で時間が動く／Esc でも閉じて動く
- [ ] 左上：第1週・曜日と時刻・残り◯秒・「第1話 放送まで あと4週」・曜日のゲージ

## 2. 右上の操作
- [ ] 停止／再開、スペースキーでも
- [ ] ×1／×2
- [ ] ？ → 遊び方 → 閉じる／Esc ／ 最初からやり直す → やり直す／やめる

## 3. 席
- [ ] 進行3人（佐伯＝左手前、川口＝右奥、真壁＝右手前）を押す → そばに指示が出る。もう一度押す／部屋の何もないところを押す／Esc で消える
- [ ] 川口と真壁が重なっているところは、手前に描かれている方が選ばれる（川口は頭のあたりを押せば選べる）
- [ ] 1〜3キーで進行を選べる
- [ ] 状態でポーズが変わる：指示待ち＝待機、作業中＝作業（営業は電話）、報告あり＝報告、疲れている＝疲労、夜の手すき・休憩＝睡眠（zZZ）、外回り中＝いない（椅子だけ）
- [ ] 名札：指示待ち・報告ありは黄色。作業中は作業名と進み
- [ ] 仕事が終わると報告の吹き出し。押すまで消えない。押すと消えて、指示の上の欄に「さっきの報告」
- [ ] 時間帯で部屋が昼・夕・夜に変わる
- [ ] ホワイトボード：全12話の工程と状況（未着手／営業／作打ち／原画／動画・仕上げ／撮影／完成、状況は進行中・遅れ気味・要確認・回収待ち、放送済みは完成・止め絵・落とした）

## 4. 指示（進行のそば）
- [ ] 原画マン営業 → どの話数？（空き・放送まで）→ 押すと取りかかる。話数が1つだけなら、すぐ取りかかる
- [ ] 作打ち（営業してから）・進行表 も同じ
- [ ] 回収へ（車が出ているときは「車を使用中」で押せない）
- [ ] 休ませる（体力が十分なら「体力は十分」で押せない）
- [ ] 作業中なら「やめさせる」
- [ ] 指示の下の欄：名前・状態・体力・いまやっていること・さっきの報告・あなたの見立て

## 5. 車の鍵とスマホ
- [ ] 机の車の鍵を進行までドラッグ → 回収へ出る（鍵が机から消える）。出せない相手は理由が出る。押すだけだと案内が出る
- [ ] 机のスマホを押す → 画面手前にスマホ。原画マンからの連絡が読める。未読の数が机のスマホに出る
- [ ] 「机に戻す」／スマホの外を押す／Esc でしまう

## 6. 週の終わりと放送
- [ ] 1週たつと「第N週 おわり」→「第1話 放送まで あと◯週」→「第N+1週へ」で次の週（新しい話数のコンテが上がる）
- [ ] 第4週の終わりに第1話が放送 → 結果（完成／止め絵／落とした）と「放送中 残り11話」
- [ ] 放送中の左上：「放送中 残り◯話」「次は第◯話（あと◯週）」
- [ ] 第15週の終わりに第12話が放送 → 全12話 放送終了（評価・各話の結果）→ もう一度

## 7. 保存と再開
- [ ] 途中で再読み込み → 同じ時刻・同じ状態で、止まった状態から再開
- [ ] 週の終わりの画面で再読み込み → その画面のまま
- [ ] 放送終了の画面で再読み込み → その画面のまま

## 8. スマホ幅（縦持ち 390×844）
- [ ] 上に時刻・放送まで・停止・×1／×2・スマホ・遊び方（44px以上）。その下にシーン
- [ ] 進行を押すと、指示が読める大きさで画面の中に出る
- [ ] スマホ（連絡）が画面に収まる
