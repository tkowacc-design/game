# 進行RTS（試作） 画面ルート一覧（テスト用）

対象は `anime-rts.html`。大きな修正のあとは、この一覧のすべてを実際に操作して確かめる。画面や操作を足したら、この一覧にも足す。

確かめること（どのルートでも共通）
- ページエラー・コンソールエラーが出ない
- 画面の文字に `undefined` `NaN` `[object Object]` が出ない
- 選んだものが黄色の枠で示され、右（狭い画面では下）に詳細が出る
- 詳細のいちばん下に「〇〇にできること」があり、押せない操作は理由が書いてある
- 原画マンの本当の進み具合（数字）は出ない。出るのは「見た」「電話で聞いた」ときの言葉（手つかず／描きはじめ／半分くらい／もうすぐ／上がり）と、あなたの見立て
- 横スクロールが出ない（1440 / 1024 / 768 / 390 / 320 px）
- 時間は requestAnimationFrame で進む。結果は1秒ほど待ってから測る

## 1. はじめる
- [ ] 初めて開く → 遊び方のダイアログ（止まっている）→「はじめる」で時間が動く
- [ ] Esc でも閉じて動き出す

## 2. ヘッダー
- [ ] 時計（N日目 hh:mm）と「局納品まで」が進む
- [ ] 「止める」「動かす」、スペースキーで止める・動かす
- [ ] 速さ：等速・2倍・4倍（押すと止まっていても動き出す）
- [ ] 電話が鳴ると「電話に出る（N）」に変わる → 押すとその電話が選ばれる
- [ ] 「遊び方」→ ダイアログ → 閉じる／Esc
- [ ] 「最初から」→ 同じ配置でやり直す／別の配置でやり直す／やめる

## 3. 一覧と地図（左・中央）
- [ ] 電話・制作進行（3人）・原画マン（8人）・場所（本社・撮影スタジオ・ファミレス・喫茶店）をそれぞれ選ぶ → 右の詳細が切り替わる
- [ ] 地図の家・本社・スタジオ・ファミレス・喫茶店・進行の車を押す → 選ばれる
- [ ] 1〜3キーで進行を選べる
- [ ] 進行を選んだまま、地図の原画マンの家を右クリック → 回収（袋がなければ発注）／スタジオ → 届ける／本社 → 休む
- [ ] 現場の記録（地図の下）が増えていく

## 4. 詳細と、できること
- [ ] 本社：見立て・袋のいま・電話が鳴ったとき（止める／等速に落とす／そのまま）・記録 ／ 時間を止める・動かす、遊び方
- [ ] 原画マン：行かせる進行を選ぶ ／ 袋の数 ± （1〜4）／ 発注に行かせる ／ 回収に行かせる ／ 張り込ませる ／ 描きかけを引き上げさせる ／ あなたが電話する（通話中は押せない）
- [ ] 袋がない原画マンでは、回収・張り込み・引き上げが押せず理由が出る
- [ ] 制作進行：いまの用事 ／ 決まった返事（4種類の選択）／ 撮影スタジオに届ける ／ 本社に戻って休む ／ 用事を取り消す ／ 電話待ちなら「電話に出る」
- [ ] 撮影スタジオ：入っている袋 ／ 上がりを持っている進行に届けさせる
- [ ] ファミレス・喫茶店：よくいる原画マン（分かっていれば）

## 5. 電話
- [ ] 「原画さんいません！」：1時間待て ／ ファミレス・喫茶店を見てこい ／ 置き手紙 ／ 持って帰れ（発注のときだけ）／ こっちから電話する（1回だけ・通話中は押せない）
- [ ] 「袋の中が白紙」：張りつけ ／ そのまま持っていけ ／ 置いて次へ
- [ ] 「渋滞」：抜け道 ／ そのまま ／ 引き返せ
- [ ] 「もう限界」：寝ろ ／ もう少し
- [ ] 出ないでいると切れて「出られなかった」になり、進行が自分で決めた結果が記録に残る
- [ ] 決まった返事を設定した種類の電話は鳴らず、「決まった返事」として残る
- [ ] 電話が鳴ったときの設定どおり、止まる／等速に落ちる／そのまま

## 6. 結果
- [ ] 全部の袋の撮影が終わる → 結果（納品・評価・作画の出来・現場の記録）
- [ ] 8日目18時を過ぎる → 結果（落とした）
- [ ] 同じ配置でもう一度 ／ 別の配置で ／ 現場を振り返る（閉じたあと、ヘッダーの「結果を見る」で戻れる）

## 7. 保存と再開
- [ ] 途中で再読み込み → 同じ時刻・同じ状態で、止まった状態から再開
- [ ] 電話が鳴っている状態で再読み込み → 鳴ったまま再開
- [ ] 結果の画面で再読み込み → 結果のまま
