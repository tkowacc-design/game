# 進行RTS（試作） 画面ルート一覧（テスト用）

対象は `anime-rts.html`（制作デスクの一人称・1週＝120秒）。大きな修正のあとは、この一覧のすべてを実際に操作して確かめる。画面や操作を足したら、この一覧にも足す。

確かめること（どのルートでも共通）
- ページエラー・コンソールエラーが出ない
- 画面の文字に `undefined` `NaN` `[object Object]` が出ない
- 押したもの（進行・スマホ・モニター・社用車・話数）の詳細が右（狭い画面では下）に出て、いちばん下に「〇〇にできること」がある。押せない操作は理由が書いてある
- 品質や進み具合の見込みは「あなたの見立て」のひとことで出る（撮影済みのカット数など、確定した数は数字でよい）
- 横スクロールが出ない（1440 / 1024 / 768 / 390 / 320 px）
- 時間は requestAnimationFrame で進む（等速で1週＝120秒）。結果は1秒ほど待ってから測る

## 1. はじめる
- [ ] 初めて開く → 遊び方（止まっている）→「はじめる」で時間が動く／Esc でも閉じて動く
- [ ] ヘッダー：第1週・「第1話 放送まで あと4週」・月〜日のゲージ・「この週 残り◯秒」

## 2. ヘッダー
- [ ] 止める／動かす、スペースキーでも
- [ ] 2倍（もう一度押すと等速）
- [ ] 遊び方 → 閉じる／Esc
- [ ] 最初から → やり直す／やめる

## 3. 席（シーン）と下のボタン
- [ ] 進行3人（佐伯・川口・真壁）を押す → 右に進行の詳細。下のボタンからも同じ
- [ ] 1〜3キーで進行を選べる
- [ ] 指示待ちの進行は立って手を振り、名札が黄色（指示待ち ◯時間）
- [ ] 作業中は座って、作業名と進み（あと約◯時間）が出る。夜の作業は机のライトがつく
- [ ] 外回り中は椅子が空く。社用車が机のトレーから消え、「社用車：◯◯が使用中」
- [ ] 夜（0〜7時）、仕事のない進行は机で寝ている（zZZ）
- [ ] 仕事が終わると、報告の吹き出しが出る。押すまで消えない。押すと消えて、その進行の詳細に「さっきの報告」が出る
- [ ] ホワイトボード・モニターを押す → モニターの詳細（話数）
- [ ] スマホを押す → スマホの詳細（未読が消える）。原画マンからカットを返されると未読が増え、画面が光る
- [ ] 社用車を進行の席までドラッグ → 外回りに出る。出せない相手（もう外回り中など）は理由が出る。押すだけだと案内が出て社用車の詳細へ

## 4. 詳細と、できること
- [ ] 進行：話数を選ぶ ／ カット表を埋める（営業）／ 作打ちの段取り ／ 発注表 ／ 香盤表 ／ 進行表 ／ 外回り ／ 寝かせる ／ いまの作業をやめさせる。押せないものは理由（空きがない・済んでいる・社用車がない など）
- [ ] 作業中の進行に別の指示を出すと、いまの作業はやめる（記録に残る）
- [ ] モニター：話数・原画マン・記録のタブ。話数を押すと話数の詳細
- [ ] 話数：カットの流れ（進行表がないと原画中・上がりは「分からない」）、表の有無、手の空いた進行に指示を出す
- [ ] 社用車：進行ごとに「外回りに出す」（ドラッグの代わり）
- [ ] 詳細の × で、モニターの詳細に戻る

## 5. 週の終わりと放送
- [ ] 1週たつと「第N週 おわり」→「第1話 放送まで あと◯週」→「第N+1週へ」で次の週（新しい話数のコンテが上がる）
- [ ] 第4週の終わりに第1話が放送 → 結果（完成／止め絵でしのぐ／落とした）と「放送中 残り11話」
- [ ] 放送中のヘッダー：「放送中 残り◯話」「次は第◯話（あと◯週）」
- [ ] 第15週の終わりに第12話が放送 → 全12話 放送終了（評価・各話の結果）→ もう一度

## 6. 保存と再開
- [ ] 途中で再読み込み → 同じ時刻・同じ状態で、止まった状態から再開
- [ ] 週の終わりの画面で再読み込み → その画面のまま
- [ ] 放送終了の画面で再読み込み → その画面のまま

## 7. スマホ幅（390px）
- [ ] シーンが画面の幅に縮み、下のボタン（進行3人・スマホ・モニター・社用車）が44px以上で押せる
- [ ] 押すと詳細までスクロールする
- [ ] ダイアログが画面に収まり、スクロールできる
