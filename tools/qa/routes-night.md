# 原画回収の夜（試作） 画面ルート一覧（テスト用）

対象は `anime-night.html`（スマホの絵だけ `assets/rts/phone-body.webp` を使う）。PCゲーム（スマホ向けには作らない）。制作進行の一人称で、1晩（22:00〜朝9:00）に第7話の原画を集める。何をしても時間が進むターン制（自動では時間は進まない）。大きな修正のあとは、この一覧のすべてを実際に操作して確かめる。画面や操作を足したら、この一覧にも足す。

確かめること（どのルートでも共通）
- ページエラー・コンソールエラー・画像の読み込みエラーが出ない
- 画面の文字に `undefined` `NaN` `[object Object]` が出ない
- 横スクロール・縦スクロールが出ない（1920×1080 / 1440×900 / 1280×720 / 1024×768）
- 押せない操作は、ボタンの文字が理由になる（「上がっているカットがない」「差し入れを持っていない」「寝ている」「まだ眠くない」など）
- 見込みは「あなたの見立て」のひとことで出る（カット数・時刻など確定した数は数字でよい）
- 時間が進む操作のあとは、時計と車が動き終わるまで（最大2秒ほど）待ってから測る

## 1. はじめる
- [ ] 初めて開く → 遊び方 →「はじめる」で 22:00・スタジオから始まる
- [ ] 左上：時刻・「朝9時の撒きまで あと11時間00分」・体力のゲージ・車の中／会社 ◯/60／差し入れ・見立てのひとこと
- [ ] 右上：？ → 遊び方 → 閉じる／Esc ／「最初から」→ 同じ夜をもう一度／別の夜／やめる
- [ ] 右下：さっき起きたこと（新しい順に3つ）。操作の結果は上のお知らせにも出る

## 2. 地図と場所
- [ ] 場所は10か所（スタジオ・原画マンの家6・コンビニ2・ファミレス）。家には住んでいる原画マンの名前
- [ ] 場所の上の札：家は「上がり ◯:◯◯」「上がってる」「寝てる」「止まってる」「留守」「回収済み」「バイク便」、スタジオは「会社に ◯」
- [ ] 何も選んでいないとき、右の列は原画マン6人の一覧（名前・家・回収 ◯/◯・札・あなたの見立て）。名前を押すと、その人がいるはずの場所が選ばれる
- [ ] 場所を押す → 右の列に、わかっていること（言っていた上がり・その人のあてになり具合・最後に見たとき・回収 ◯/◯・機嫌・あなたの見立て）と、いちばん下にできること。もう一度押す／「一覧へ」／地図の何もないところ／Esc で一覧に戻る
- [ ] 右の列は、どの場所でもスクロールなしで収まる（寝ている人を起こすボタンが増えたときは、列の中でスクロールしてよい）
- [ ] いない場所：「ここへ行く（着くのは◯:◯◯）◯分」。戻ると9時を過ぎる場所は「戻ると9時を過ぎる」と出る。9時までに着けないスタジオは押せない
- [ ] 行く → 車が道に沿って動き、時計が進む。着くと、上がっているカット数・寝ていた・他社の作業中・手が止まっていた・留守 が上の札と右下に出る
- [ ] 夜明け（5時ごろから）に地図が少しずつ明るくなる

## 3. 原画マンの家で
- [ ] 上がった分を回収（10分）：上がっている分だけもらう（途中でも可）。全部もらうと「全部回収した。もう用はない」
- [ ] 横で待つ（30分）：待つあいだは少し早く描く。結果に「+◯」
- [ ] 急かす（5分）：2時間は早く描くが機嫌が悪くなる。機嫌が悪いと、へそを曲げて1時間止まる
- [ ] 差し入れを渡す（5分）：コンビニで買ったものが要る。機嫌がよくなり、少し早く描く
- [ ] 話を聞く（20分）：機嫌がよくなる。手が止まっている人は描き始める
- [ ] 起こす（寝ているときだけ）・こっちを先にと頼む（他社の作業中だけ）：効くが機嫌が悪くなる
- [ ] 描き終わった人には「回収」だけが出る

## 4. コンビニ・スタジオ・ファミレス
- [ ] コンビニ：差し入れを買う（10分、3つまで）・車で仮眠（30分、体力が多いと押せない）
- [ ] スタジオ：原画を置く（5分）・机で仮眠（60分）・今夜はここまで（帰って寝る）→ 確かめ → 結果
- [ ] 柴田が逃げたあとは、家に行くと「留守だった」。ファミレスで会える（電話に出ていれば最初から「ファミレスにいる」とわかる）

## 5. 電話
- [ ] 夜のあいだにスマホが鳴る（デスク2回・小野寺・石黒・柴田・森下・原・高槻・同僚の真壁）。鳴っているあいだは他の操作はできない
- [ ] 「出る」→ 話の中身と選択肢 ／「出ない」→ 中身はわからない（デスクの電話に出ないと信用が下がる、など）
- [ ] 選んだ結果が上のお知らせと右下に出る（例：原のバイク便 → 朝8時に会社に届く）
- [ ] 高槻の家にいるときに高槻が描き終わっても、電話は鳴らない

## 6. 体力と朝
- [ ] 体力が減ると「眠い」「限界」。25未満で移動が遅くなる。0になると居眠り（45分たつ）
- [ ] 9:00 になると結果：評価（S〜D）・会社に入った原画・車に残った原画（スタジオにいなかったとき）・バイク便・回収できなかった数・徹夜したか・明日の体力・居眠り・デスクの信用・真壁に貸し・原画マンごとの機嫌・電話に出た回数
- [ ] 結果 →「同じ夜をもう一度」（同じ並び）／「別の夜」

## 7. 保存と再開
- [ ] 途中で再読み込み → 同じ時刻・同じ場所・同じ状態（開いていた場所の説明も）
- [ ] 電話が鳴っているときに再読み込み → また鳴っている
- [ ] 結果の画面で再読み込み → 結果のまま
