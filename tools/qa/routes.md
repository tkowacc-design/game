# 深夜アニメP 画面ルート一覧（テスト用）

大きな修正のあとは、この一覧のすべてを実際に操作して確かめる。画面や操作を足したら、この一覧にも足す。

確かめること（どのルートでも共通）
- ページエラー・コンソールエラーが出ない
- 画面の文字に `undefined` `NaN` `[object Object]` が出ない
- 選んだものが黄色の枠で示され、右（スマホでは下）に詳細が出る
- 詳細のいちばん下に「〇〇にできること」があり、押せない操作は理由が書いてある
- 行動を使う操作は「行動N」、使わない操作は「行動なし」と出る
- 品質の見込みが数字で出ていない（あなたの見立てのひとことで出る）。放送後の「作画の出来」と最終評価は数字でよい
- 横スクロールが出ない（1440 / 1024 / 768 / 390 / 320 px）

## 1. スタジオを選ぶ（タイトル）
- [ ] 3つのスタジオ（極光・ひばり・夜明け）をそれぞれ選ぶ → 右の詳細が切り替わる
- [ ] 「このスタジオで始める」→ グランドスケジュールへ（3つとも）
- [ ] 「遊び方」→ ダイアログ → 閉じる／Esc
- [ ] ベスト評価が出る（一度クリアしたあと）

## 2. グランドスケジュール
- [ ] 12話の行をそれぞれ選ぶ → 右に話数の詳細と見立て
- [ ] 担当を変える（社内の班・グロス各社）
- [ ] 着手を ± する（W1より前には動かない）
- [ ] 期間を ± する（最短6週より短くならない）
- [ ] 重なり・間に合わないを作る → チェックに出る → 「制作開始」が押せない
- [ ] チェックの行を押す → その話数が選ばれる
- [ ] 協力会社を選ぶ → 右に協力会社の詳細
- [ ] 「おまかせで組み直す」→ 問題なしに戻る
- [ ] 「スタジオを選び直す」→ タイトルへ
- [ ] 「制作開始」→ 遊び方 → 制作画面

## 3. 制作画面（一覧）
- [ ] オフィス：あなたの席／各班の進行の席／各班の作監の席／監督／撮影・仕上げ／作画部屋／電話／ホワイトボード／テレビ
- [ ] 12話の帯をそれぞれ選ぶ（着手前・制作中・グロス・遅れ・納品済・放送済）
- [ ] 気になることの各行 → 対象が選ばれる
- [ ] 「グランドスケジュール」→ 大きな表 → 行を選ぶ → 右が切り替わる → 閉じる／Esc
- [ ] 「遊び方」「やめる」（→ 続ける／やめてスタジオ選びに戻る）
- [ ] 「今週を締める」

## 4. 詳細と、できること
- [ ] スタジオ（あなたの席）：方針3つ（発注先・進め方・残業）を切り替える
- [ ] 話数（制作中・社内）：巻く… ／ 原画マンを足す ＋1・＋3 ／ 進行表を開く
- [ ] 話数（制作中・グロス）：巻く… ／ 協力会社を催促
- [ ] 話数（着手前）：担当・着手・期間を変える
- [ ] 話数（納品済・放送済）：放送・SNSを見る
- [ ] 班：進行表を開く ／ 進行のヘルプに入る（行動1）／ 新しい進行を入れる（進行が飛んだとき）
- [ ] 人（制作進行）：ヘルプに入る ／ 進行表を開く ／ 体力が低い・連絡が取れないの表示
- [ ] 監督：外部コンテマンに頼む ／ 監督と打ち合わせ（機嫌が悪いときだけ押せる）
- [ ] 部署：発注先の切り替え
- [ ] 協力会社：第N話を催促
- [ ] 放送・SNS：1枚絵・SNS・現場ログ
- [ ] 行動が0のとき、行動を使う操作が押せず理由が出る
- [ ] 関係するもの（班・人・協力会社）を押す → その詳細へ

## 5. ダイアログ
- [ ] 巻く：各巻き方を選ぶ → 週の棒・見立て・結論が変わる → 指示する／やめる／Esc
- [ ] 進行表：タブを切り替える ／ ヘルプに入る ／ 原画マンを足す ／ × ／ Esc ／ 作画部屋（全話の一覧）
- [ ] 報告（トラブル）：選択肢をそれぞれ選ぶ。行動が足りない選択肢は押せない
- [ ] ヘルプで見つかった報告・遅れて来た報告の表示
- [ ] 納品拒否（局P）：リテイク／総作監／頭を下げる
- [ ] 放送日に間に合わない：このまま放送（基準割れなら押せない）／総集編（2回まで）／延期
- [ ] 放送：出来・評判・1枚絵・SNS → 次へ

## 6. 最終評価
- [ ] 全12話を放送しきる → 評価・グラフ・1枚絵・現場の記録
- [ ] 結果をコピー（コピーできないときは選択状態になる）
- [ ] 同じスタジオでもう一度 ／ スタジオを選び直す
- [ ] ベスト更新の表示

## 7. 保存と再開
- [ ] 制作中に再読み込み → 同じ週・同じ状態で再開
- [ ] 報告や放送日のダイアログが出ている状態で再読み込み → そのダイアログから再開

## 8. スマホ幅（390px）
- [ ] 週と「今週を締める」が画面の下に固定される
- [ ] 一覧を押すと詳細までスクロールする
- [ ] ダイアログが画面に収まり、スクロールできる
