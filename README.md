# 深夜アニメP（`anime-producer.html`）

アニメのプロデューサーになって、TVアニメ1クール（全12話）を放送まで届ける経営シミュレーションです。スコアは決算でいくら黒字になったか。

- `anime-producer.html` をブラウザで開くだけで動きます（外部ライブラリなし）。
- 流れ：スタジオ選び（有名・中堅・弱小＝難易度）→ 企画 → 座組（監督・シリーズ構成・制作デスク・主演声優）→ 製作委員会で資金集め → 毎週の制作と放送 → 決算。
- 制作中の画面は夜のスタジオ（ドット絵）。デスク・進行・作監・原画マン・監督・撮影部屋・ホワイトボード（香盤表）・電話・テレビを押すと、右のパネルにその人や班の状況が出ます。
- 各話は 脚本 → コンテ → 原画 → 作監 → 動画・仕上げ → 撮影 の順にカット単位で流れます。原画マンは「持ちカット」を描き終えると、デスクが次の話数を振ります。プレイヤーは原画マンを別の話数に回したり、作監を付け替えたり、放送直前に作監を飛ばしたりできます。
- 制作費は業界の一般的なサンプル（1話 約1,282万円、17費目＋制作管理費15%）を最低ラインに、スタジオと座組の単価ランク（×1.0〜3.0）を掛けて決まります。実際の支出は工程が進むたびに費目ごとに積み上がり、決算で見積もりと実績を比べられます。
- デスク・進行への指示：原画の発注先（国内のみ／海外も可）、動画・仕上げの発注先、単価、進め方、残業。
- 赤字を受け入れて人とお金をつぎ込めば、どのスタジオでも全話放送でき、最悪でも1話落とす程度になるよう調整しています（シミュレーションで確認）。それ以外の難易度調整はこれからです。
- ゲームの計算部分（`<script id="engine">`）は画面と分かれていて、Node でも読み込めます。

# 棒立ち勇者 Lv.99

異世界の草原で、レベル99の鎧の勇者がスライムの群れにひたすら攻撃され続ける 3D シーンです。
勇者は棒立ちのまま。ダメージは常に 0 です。

- `index.html` をブラウザで開くだけで動きます（three.js r128 を cdnjs から読み込みます）。
- ドラッグで視点を回転、ホイール / ピンチでズーム（カメラは自動では回りません）。
- コマンド「たたかう / ぼうぎょ / どうぐ / にげる」を選んでも、勇者は何もしません。
- 「スライムをよぶ」でスライムが増えます（最大 48 匹）。ときどきオオスライムも来ます。
- 「おと」で効果音を ON / OFF できます（初期値は OFF）。

## 棒立ち騎士とゴブリン（`goblins.html`）

アップロードされた騎士とゴブリンのモデルを使った版です。騎士1人をゴブリン4匹（騎士の約3分の1の大きさ）が攻撃し続けます。

- ゴブリンA：きりかかり／B：3連続づき／C：ジャンプぎり／D：投石（左手）
- 攻撃のたびに、斬撃の軌跡・衝撃の光・火花・騎士を包む金色の障壁が光ります。会心の一撃では画面が光り、一瞬スローになります。
- 「いっせいこうげき」で4匹が同時に攻撃します。
- モデルは `models/knight.json` と `models/goblin.json` を読み込みます。読み込めない場合は内蔵の仮モデルで動きます。
  - モデルファイルは、リグ入り FBX（`newknight/`、`ゴブリン+3dモデル/`）から変換した glTF（データ埋め込み形式、拡張子 .json）です。テクスチャを 1024px に縮小し、ポリゴン数を削減しています。
  - アニメーションデータは入っていないため、Mixamo 形式のボーンをコードで動かしています。騎士は MMO の放置中のような待機ポーズで呼吸だけ、ゴブリンは剣を握り直した構え・歩き・攻撃の各動作をボーンで付けています。
- モデルの読み込みには HTTP サーバーが必要です（例：`npx http-server` で開く）。`file://` で直接開くと仮モデルになります。
