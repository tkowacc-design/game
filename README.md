# 深夜アニメP 制作デスク篇（`anime-producer.html`）

> **RTS版の試作（`anime-rts.html`、絵は `assets/rts/`、PCゲーム）**：制作デスクの席から見たドット絵の一人称画面。常設のパネルはなく、制作進行を押すとそばに指示が出る。1週間＝120秒、全12話で1話のスケジュールは4週（炎上中）。話数は進行3人の担当制。指示は原画営業・作打ち・動仕撒き・撮入れ準備（棚にカット袋がたまる）・外回り（1人で全員の話数の回収と、棚の袋の撮影への届けをまとめてやる）・休憩・寝る・帰宅・今夜は徹夜（週1回）。進行は10時に出社して24時に帰宅する。社用車は1台で、机の車の鍵を進行にドラッグすると外回り。右手前のパソコンで進行表（あと何人足りないか、どこで止まっているか）・原画マン・グロス。机のスマホにメールが来て「受け入れる」か「キレて出させる」で返事（同じ相手には一度だけ）。難易度は最初に原画マンがどれだけ埋まっているか（やさしい8割・ふつう6割・きびしい5割）。

アニメスタジオの**制作デスク**になって、TVアニメ1クール（全12話）を放送まで落とさずに届けるシミュレーションです。お金（予算・製作委員会・宣伝）は扱いません。

- `anime-producer.html` をブラウザで開くだけで動きます（外部ライブラリなし）。
- **キャンペーン「流しのデスク」（全5章・結末2種類）**：どこの会社にも属さない制作デスクとして、燃えかけた現場に途中の週から入り、放送まで持たせる。前任が残した問題（進行の失踪、抜けた原画マン、止まったグロス、監督の機嫌、ずれた日程）を引き継ぐ。現場をやり遂げると評判と人脈（腕のいい原画マン。次の現場で呼べる）が残る。5年前に放送されなかった『ステラ・ノクターン』最終話の謎を追う縦軸のストーリーつき。第4章で真相（最終話の進行は自分で、原画の回収漏れを「順調」と報告していた）が明かされ、朝比奈に打ち明けるかを選ぶ。終章は再結成した夜鷹スタジオで最終章を第1週から作る。打ち明けて、終章を評価B以上・総集編と延期なしでやり遂げると結末A「最終話、放送」、それ以外は結末B「流しの夜は続く」。フリープレイ（スタジオを選んで1クールを最初から）も残している。
- **画面の作り**：どの画面も「左に一覧（オフィスの人・12話の帯・気になること など）→ 選ぶと右に詳細 → 詳細のいちばん下に、それにできること」。いまの週と「今週を締める」はヘッダー（スマホでは画面の下）。ダイアログ（報告・巻く・放送）も同じ形。
- **あなたの見立て**：品質の見込みは数字で見せず、制作デスク自身のひとこと（「良い感じだ」「ちょっと作画厳しいか・・・？」「スケジュールが無い・・・」「撮影にものが入ってない」など）で示す。
- 流れ：スタジオ選び（有名・中堅・弱小＝難易度）→ **グランドスケジュール** → 毎週の制作と放送 → 評価（S〜D）。
- **座組はスタジオで決まる**：作品・監督・シリーズ構成・班の数・各班の制作進行（段取りの良し悪し）・作監・放送前の制作期間は、選んだスタジオごとに固定。弱小ほど進行が新人揃い。
- **グランドスケジュール**：各話をどの班で、いつから作るかを決める。1話は標準8週（最短6週）、1班は同時に1話まで。社内で間に合わない話数は協力会社に**グロス**（1話まるごと）。「おまかせ」でも組める。着手前の話数は制作中も組み替えられる。
- **班の進行表**：オフィスで班や制作進行を選び「進行表を開く」と、スプレッドシート風の進行表が開く（右には話数の詳細）。原画マンごとの ラフ原・原画 の進みと、別ブロックで各部署の **動画・仕上げ・撮影の進捗率** と 美術・CG の状況。原画マンは1話10人から何人でも足せるが、10人を超えると1人あたり品質 −0.6。
- **トラブルは進行が報告してくる**：原画マンの連絡不通・他社優先、原画の回収漏れ、カット袋の紛失、カットの二重発注、演出が捕まらない、作監修正の山・作監ダウン、作監リテイク、色指定ミス、撮影データ消失、局の考査NG、海外動画の品質、進行車の駐禁、監督のこだわり、原作監修、協力会社の遅れ、インフル等。シリーズの後半ほど起きやすい。
- **間に合わないときの巻き**：完パケ予測が放送週を過ぎると、進行（グロス回は協力会社）がその工程で打てる手を持ってくる。進行表からも指示できる。
  - 原画中：**24時間動仕 → 12時間動仕 → 2原動仕**（原画から仕上げまでを飛ばす）。下ほど早く上がるが、カットの仕上がりが悪くなる。
  - 撮影に入ってから：**撮影スケジュールの短縮**（品質が大きく下がる）。
  - 品質の低下は「その話数全体にかかる分」＋「巻いて通したカットの割合に応じた分」。
- **納品拒否**：局・製作委員会の納品基準は品質50。完パケ（グロス回は納品）の時点で下回ると局プロデューサーから納品拒否され、リテイクになる。
  - 社内回：原画からリテイク（足りない分に応じて20カット〜）／総作監に修正を入れてもらう（行動2・撮影からやり直し）／局Pに頭を下げる（行動1・五分五分、だめなら原画リテイク）。
  - グロス回：協力会社にリテイク（あと2週）／社内で引き取る（行動2・あと1週）／局Pに頭を下げる。
  - 基準を下回る話数は、放送日に「このまま放送」もできない（総集編か延期）。巻きの見込みに「基準割れ」が出る。
- **無能な進行は隠す**：段取りの悪い進行はトラブルを抱え込み、報告を遅らせる（最悪は放送2週前まで）。その間、進行表の数字は順調に見える。進行の**ヘルプに入る**（行動1）と現場の本当の状況が分かり、隠れていたトラブルが出てくる。
- 毎週の行動は3回（ヘルプ、新しい進行を入れる、外部コンテ、監督と話す、協力会社の催促）。原画マン追加と現場への指示（動画・仕上げの発注先、作り置き／品質優先、残業）は行動を使わない。
- 評価は全12話の平均の出来から、作画崩壊・総集編・放送延期とスタジオの有利さを差し引いて決まる。難易度調整はこれから。
- ゲームの計算部分（`<script id="engine">`）は画面と分かれていて、Node でも読み込める。
